# Karnataka e-KYC Android Releases

Public binary-only update feed for the Karnataka Ration Card e-KYC Android application. The application source remains in the private `mrnaddu/Kyc` repository.

## Download

Download the latest signed APK from [Releases](https://github.com/mrnaddu/Kyc-Releases/releases/latest).

Version 1.2.0 establishes the permanent Android signing identity. If version 1.1.0 is installed, uninstall it once before installing 1.2.0. Future releases can then update through **Check for updates** inside the app.

> This is a development project for testing and is not an official Government of Karnataka or UIDAI application.
